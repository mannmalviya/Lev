# Asset sources

- `flappy/`: from https://github.com/sourabhv/FlapPyBird (MIT). The art is from the original Flappy Bird game by Dong Nguyen. Used here for a hackathon demo only.
- `dino/`: from Chromium's offline dino game, via https://github.com/wayou/t-rex-runner (BSD-3-Clause, Chromium authors).
- Fonts in `src/app/fonts/`: Virgil (Excalidraw, OFL-1.1) and ET Book (Edward Tufte, MIT).
